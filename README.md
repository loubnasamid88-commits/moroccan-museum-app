# Moroccan Museum App

## About the Project

**Moroccan Museum App** is a digital initiative designed to promote Morocco's rich cultural heritage by making museums, historical collections, and cultural treasures more accessible through technology.

Our project aims to transform cultural memory into opportunities for the future by encouraging people to discover Moroccan history, explore artistic heritage, and appreciate the country's cultural identity.

Developed as part of our interest in digital innovation and heritage preservation, the application contributes to the vision of the **Memory, Heritage, Innovation & Investment Hackathon**.

## Objectives

- **Preserve Cultural Memory:** Support the digital promotion of Morocco's historical and cultural heritage.
- **Promote Moroccan Museums:** Help users discover museums and their collections.
- **Improve Accessibility:** Provide a user-friendly digital experience for exploring cultural information.
- **Encourage Innovation:** Use web technologies to create new ways of discovering and sharing cultural knowledge.
- **Strengthen Cultural Identity:** Highlight the diversity and richness of Moroccan traditions and history.

## Our Vision

We believe that technology can play an important role in preserving cultural heritage and connecting younger generations with their history.

Through Moroccan Museum App, we aim to make cultural discovery more engaging, accessible, and relevant to the digital generation.

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/loubnasamid88-commits/moroccan-museum-app.git
```

Navigate to the project folder:

```bash
cd moroccan-museum-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal.
